# For Elii 💕

A cute Valentine's page asking Elii to be your remote Valentine.

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**.
4. Branch: **main** (or **master**), folder: **/ (root)**.
5. Save. The site will be at `https://<your-username>.github.io/elii/`.

## Music (Careless Whisper)

The page has a music button that plays **Careless Whisper**. Add an MP3 file named `careless-whisper.mp3` in the same folder as `index.html` (e.g. from your own copy of the song). The button in the bottom-right corner starts and pauses the music.
